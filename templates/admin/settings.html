Setări site

Ajustezi numele și identitatea vizuală fără să schimbi codul — util când rulezi același container pentru alt blog. Setările text + imagini se salvează în db/site_settings.json.

URL public (pentru OG, TinyMCE, link-uri canonice) vine doar din .env PUBLIC_SITE_URL{% if env_public_url %}: {{ env_public_url }}{% else %}: nelsetat — se folosește hostul din request{% endif %}. Caddy decide domeniul; aici nu îl mai duplicăm.

Token Telegram și SESSION_SECRET rămân în .env.
